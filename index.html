New ingredient

Enter calories for exactly one unit as selected above (e.g. calories per 1 gram, or per 1 each). The unit is just a reference for calories — on the shopping list, amounts are automatically totaled and shown in whichever size (g/kg, tsp/tbsp/cup/L, etc.) makes the most sense, so you never need to do the math yourself.

Custom units (optional)

Add other units recipes might use for this ingredient — smaller ones (10 cloves = 1 bulb) or larger ones (1 bulb = 10 cloves), whichever direction makes sense. Recipes can then use any of these units directly, and the shopping list converts and combines everything automatically. Any unit marked "larger" also becomes selectable as the pricing unit below (e.g. price per bulb instead of per clove).

Leave this blank for almost everything. It only matters if you sometimes measure THIS ingredient by volume (cup/tbsp/tsp) and other times by weight (g/kg/oz/lb) — e.g. one recipe says "2 tbsp honey", another says "50 g honey". Filling this in lets those combine correctly on the shopping list. A quick web search for "[ingredient] grams per cup" will give you a good number.

Pricing, by store (optional — add now or anytime later by reopening this ingredient)

Check this for things like a box of pasta or a block of cheese. Leave it unchecked for things sold as exactly what you need, like deli meat sliced to order. When checked, enter each store's package size below — the shopping list will round up to the number of whole packages you'd actually need to buy, and any extra left over from rounding up gets automatically added to your pantry once you check it off while shopping. If you've defined a "larger" custom unit above (like bulb), each store also gets a unit dropdown so you can price and size packages in that unit directly instead of converting by hand.

Leave a store blank if you don't know the price there — the shopping list will just skip it for that item.

Quick add multiple ingredients

Names that match something in Recipeo's built-in list (common pantry staples, produce, proteins, spices, etc.) get their emoji, unit, and calories filled in automatically. Anything else still gets created — just with a blank emoji and 0 calories for you to fill in later. Names that already exist in your library are skipped.
